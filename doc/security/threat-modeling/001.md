Modelo de amenazas STRIDE

Endpoint: GET /api/v1/products/{id}

S - Spoofing	Suplantación de identidad	Uso de un JWT/API Key robado	OAuth 2.0, validar JWT, expiración de tokens y TLS 1.2+
T - Tampering	Manipulación del id	Cambiar /products/100 por /products/101	Validar {id}, consultas parametrizadas y autorización sobre el producto
R - Repudiation	Falta de trazabilidad	Usuario niega haber realizado una consulta	Logs de auditoría, usuario/clientId, timestamp y correlationId
I - Information Disclosure	Exposición de información	La respuesta muestra datos internos, sensibles o stack traces	DTO de salida, ocultar datos sensibles y controlar errores
D - Denial of Service	Saturación de la API	Miles de consultas consecutivas	Rate limiting, timeouts, circuit breaker y monitoreo
E - Elevation of Privilege	Acceso a productos no autorizados	Usuario consulta un {id} perteneciente a otro usuario	Validar roles/scopes y autorización a nivel de objeto


Riesgos principales

Crítico: acceso a productos de otros usuarios (BOLA/IDOR).
Alto: manipulación de {id}, exposición de datos, robo de tokens y DoS.
Medio: falta de auditoría.

Controles recomendados

Autenticación + autorización por producto + validación de {id} + TLS + DTO de respuesta + manejo seguro de errores + rate limiting + logs de auditoría.
